# 扶養親族確認調査書（扶養手当）印刷システム

陸前高田市 総務部総務課 職員係が行う扶養親族資格確認調査で使う
「扶養親族確認調査書」を、人事給与システムの出力から抽出して人数分印刷するツールです。

仕様は [docs/spec.md](docs/spec.md) を参照してください。

## 特徴

- **インストール不要。** `index.html` をブラウザで開くだけで動きます。
  Python や Node.js、Webサーバの導入は不要です。
- **完全ローカル処理。** 読み込んだExcelはこのPCの中だけで処理され、外部には一切送信しません。
- **年度はパラメータ。** 対象年度を変えるだけで基準日・生年月日上限・見出しが自動で切り替わります。

## 使い方

1. このフォルダごと庁内PCにコピーする
2. `index.html` をダブルクリックして Microsoft Edge で開く
3. **対象年度**を入力する（既定は当年度。令和8年度なら `2026`）
4. **名簿データ**と**扶養データ**の .xlsx を選ぶ（用意のしかたは次項）
5. 「読み込んで抽出する」を押す
6. エラー・警告を確認し、印刷対象を選ぶ
7. 「印刷プレビューを作る」→「印刷する」

### データの準備のしかた

画面上部の「データの準備のしかた」を開くと同じ内容が確認できます。

**名簿データ（人事システム）**

1. 人事システムを開き、画面左上の検索条件で「在職」「写真無」「詳細」を選択して検索する
2. 検索結果の一覧上で `Ctrl + A` を押してすべて選択する
3. コピーしてExcelに貼り付け、「名簿データ」として `.xlsx` で保存する

**扶養データ（給与システム）**

1. 給与システムを開き、対象年度の6月を選択する
2. 「入力」→「ダウンロード」と進む
3. プルダウンから「扶養データ」を選択してダウンロードする
4. 表示された内容を `Ctrl + A` で全選択してコピーし、Excelに貼り付けて「扶養データ」として `.xlsx` で保存する

一覧を名簿・監査資料として残したい場合は、「印刷対象」画面の**一覧をCSV出力**から
Excelで開けるCSVを書き出せます（印刷のチェックとは独立して、表に表示中の行が出力されます）。

### 印刷ダイアログの設定

| 項目 | 設定 |
|---|---|
| 用紙 | A4・縦 |
| 余白 | **なし** |
| 倍率 | **100%（既定・「ページに合わせる」にしない）** |
| ヘッダーとフッター | **オフ** |

## 抽出条件

対象年度を `FY`（西暦4桁）とすると、

```
基準日       = FY年6月1日
生年月日上限 = (FY-18)年4月1日        令和8年度なら平成20年4月1日

名簿 : 在職 = 1  かつ  身分が対象外リストに該当しない
扶養 : year = FY  かつ  teate = 1  かつ  temp_kingaku > 0
                  かつ  birthday <= 生年月日上限
結合 : 扶養.number = 名簿.番号
```

事前印字するのは所属名・職員番号・職員氏名と、扶養親族の氏名・生年月日（和暦）・年齢です。
続柄・職業・総収入見込額・同居別居・配偶者欄・担当者確認欄は空欄（手書き記入）です。

## 設定の変更

`assets/config.js` を編集してブラウザを再読み込み（Ctrl+F5）してください。

| 設定 | 内容 |
|---|---|
| `excludedStatuses` | 対象外とする身分。既定は「パート（時間額）」「パート（日額）」 |
| `knownIncludedStatuses` | 対象に含めることが確認済みの身分。ここにも上にも無い身分は、対象に含めたうえでお知らせに表示します |
| `maxDependentsPerSheet` | 1枚に収まる扶養親族の上限（既定9名）。超える職員は警告を出して印刷対象外にします |
| `columns` | 列名の対応。人事給与システムの出力見出しが変わったときに直します |
| `sheetNames` | 読み込むシート名。`null` なら先頭シート |

## ファイル構成

```
index.html              アプリ本体（これを開く）
assets/config.js        設定（運用者が編集する）
assets/core.js          抽出・和暦・年齢などのロジック
assets/render.js        調査書の組版
assets/csv.js           対象扶養親族一覧のCSV出力
assets/form.css         帳票スタイル（記入例PDFの寸法に準拠）
assets/ui.css           画面スタイル
assets/app.js           画面制御
vendor/xlsx.full.min.js Excel読み込み（SheetJS, Apache-2.0）
docs/spec.md            仕様書
docs/mock/              様式の再現モック（レイアウト検証用）
test/                   単体テスト（開発用）
```

## 開発

テストの実行には Node.js が必要です（アプリ本体には不要）。

```
npm install
npm test
```

`test/fixtures/` のテストデータは実在しないダミーです。
実データ（個人情報を含むExcel）はリポジトリに置かないでください（`.gitignore` で除外済み）。
