# 画面デザインの案（5案）

`assets/ui.css` に**重ねて**読み込むと見た目が変わる差分ファイルです。
現在の画面（`assets/ui.css` のまま）と見比べて選んでください。

| 案 | ファイル | 方向性 |
|---|---|---|
| 藍（あい） | `theme-ai.css` | 和モダン。生成りの紙に藍色。影を使わず罫線で構成する。公文書らしい硬さ |
| 霞（かすみ） | `theme-kasumi.css` | ミニマル。白地・ヘアライン・影なし。余白と文字組みで見せる |
| 常磐（ときわ） | `theme-tokiwa.css` | 深緑。カード上端の色帯で章立てを示す。現在の画面に近い構成 |
| 宵（よい） | `theme-yoi.css` | ダーク。照明の暗い執務室や長時間の作業でまぶしくない |
| 陽（ひ） | `theme-hi.css` | やわらかい。角を大きく丸め、淡い影と暖色でとっつきやすくする |

## 試しかた

`index.html` の `assets/ui.css` の**次の行**に、試したい案を1行足します。

```html
<link rel="stylesheet" href="assets/ui.css">
<link rel="stylesheet" href="docs/mock/themes/theme-ai.css">   <!-- この1行を足す -->
```

元に戻すときは、足した1行を消してください。

## 採用が決まったら

差分のままでも動きますが、**配布物では `assets/ui.css` に取り込むことをおすすめします。**
`docs/` は配布用ZIPから外してよい扱いにしているため、差分ファイルだけ配り忘れると
見た目が元に戻ってしまいます（`README.md`「配布のしかた」参照）。

## 一覧を作り直す

```
python3 tools/preview-themes.py
```

テスト用ダミーデータを読み込ませた状態の画面を、案ごとに撮って
`docs/mock/themes/preview/` に出します（開発用。個人情報は含みません）。
