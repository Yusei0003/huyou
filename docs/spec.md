# 扶養親族資格確認調査書（扶養手当）印刷システム 仕様書

- バージョン: v0.1（ドラフト／仕様固め中）
- 作成日: 2026-09-14
- ステータス: **様式未確定**（後述「4. 様式・印字項目」参照）

## 1. 背景・目的

### 1.1 根拠資料

本システムは、**陸前高田市**（市レベル）の下記内部通知に基づく事務を支援する。

| 項目 | 内容 |
|---|---|
| 文書名 | 令和８年度被扶養者及び扶養親族資格確認調査の実施について（通知） |
| 文書番号 | 陸高総号外 |
| 日付 | 令和８年８月３日 |
| 発出 | 陸前高田市 総務部総務課長 |
| 宛先 | 各部課等の長 |

上記は市の**内部通知（事務連絡）**であり、条例・規則ではない。

### 1.2 未確認事項（法令根拠）

扶養手当そのものの根拠規定（陸前高田市職員の給与に関する条例の扶養手当に係る条文、
及び同施行規則における扶養親族の届出・認定手続の条文）は、**本セッションから
例規集（条例規則/現行フォルダ）を参照できないため未確認**である。推測での引用は行わない。

仕様確定前に、以下を例規集で確認し本書に条文番号とノート名を追記すること。

- 陸前高田市（市）: 職員の給与に関する条例 — 扶養手当の支給要件・扶養親族の範囲
- 陸前高田市（市）: 同施行規則等 — 扶養親族届・認定・資格確認の手続
- 参考: 国の一般職の職員の給与に関する法律（国レベル）の扶養手当規定との異同

なお、別紙１の「被扶養者資格確認調査」は**共済組合（市とは別の団体）**の制度であり、
市の扶養手当とは根拠が異なる。混同しないこと。本システムの対象は**扶養手当のみ**。

### 1.3 目的

職員係が、扶養手当の資格確認調査に用いる「扶養親族確認調査書」を、
人事給与システムから出力した対象者データをもとに**事前印字した状態で人数分印刷**できるようにする。

## 2. スコープ

### 2.1 対象

- 扶養手当に係る「**扶養親族確認調査書**」の帳票印刷
- 対象者の抽出（基準日・生年月日による絞り込み）
- 調査書への職員情報・扶養親族情報の事前印字
- 添付書類チェックリストの印字（別紙の判定ルールに基づく）

### 2.2 対象外（本フェーズ）

- 共済組合の「被扶養者資格確認調査書」の印刷
- 提出状況の進捗管理・督促
- 回収後の審査結果の登録・返納処理
- 人事給与システムへの書き戻し

## 3. 対象者抽出要件

通知【別紙】２「扶養親族資格確認調査（扶養手当）」⑴より。

| 条件 | 令和８年度の値 | パラメータ化 |
|---|---|---|
| 扶養している時点（調査基準日） | 令和８年６月１日 | `基準日` |
| 生年月日の上限 | 平成２０年４月１日**以前**の出生者 | `生年月日上限` |

- 令和８年度は「平成20年4月1日以前出生」＝「令和８年４月１日時点で満18歳以上」に相当。
- 年度ごとに値が変わるため、**両方を設定値として外出し**する（ハードコードしない）。
- 抽出条件: `扶養親族.生年月日 <= 生年月日上限` かつ `基準日時点で扶養手当の認定中`

参考（共済側・対象外だが別紙１に記載あり）: 調査基準日 令和８年６月１日／年齢の基準日 令和８年４月１日。

## 4. 様式・印字項目

> **【要対応】** 添付いただいた `02_...doc` はバイナリ解析の結果、全4ページすべてが
> 通知文と別紙であり、**調査書の様式は含まれていなかった**（本文2,080字＋ヘッダー13字＋
> テキストボックス21字で全量、埋め込みオブジェクトなし）。
>
> 「扶養親族確認調査書」の様式ファイルの提供を受けてから、本章を確定する。

確定待ちの項目:

- 用紙サイズ・向き（A4縦想定）、余白
- 1枚あたりの単位（職員1人1枚か、扶養親族1人1枚か）
- 扶養親族欄の行数（1枚に何人まで書けるか → 超過時の2枚目の扱い）
- 各記入欄の項目名・並び・罫線レイアウト
- 押印欄・所属長確認欄の有無
- 提出期限や問合せ先の刷り込み文言

## 5. 入力データ仕様（人事給与システムCSV）

### 5.1 方式

人事給与システムから出力したCSVを本システムに取り込む。

- 文字コード: Shift_JIS（CP932）／UTF-8(BOM付) の**両方を自動判別**して受け付ける
- 改行: CRLF / LF いずれも許容
- 1行目: ヘッダ行（列名で対応付ける。列順に依存しない）

### 5.2 想定項目（案 — 実際の出力項目に合わせて確定する）

**職員（扶養手当受給者）**

| 論理項目 | 必須 | 備考 |
|---|---|---|
| 職員番号 | ○ | 突合キー |
| 所属（部・課・係） | ○ | 配布仕分け・印刷順に使用 |
| 職員氏名 | ○ | |
| 職員氏名カナ | | |
| 生年月日 | | |

**扶養親族（職員1人に対し複数行）**

| 論理項目 | 必須 | 備考 |
|---|---|---|
| 職員番号 | ○ | 親キー |
| 扶養親族氏名 | ○ | |
| 扶養親族氏名カナ | | |
| 続柄 | ○ | 配偶者／子／父／母 等 |
| 生年月日 | ○ | 抽出条件の判定に使用 |
| 認定年月日 | | |
| 同居・別居区分 | ○ | 別居時の添付書類判定に使用 |
| 別居先住所 | | 別居の場合 |
| 収入区分 | | 給与報酬／年金／事業／その他／無収入 |
| 学生区分 | | 全日制／定時制・通信制・夜間／非該当 |
| 施設入所区分 | | 別紙のa／b／c区分 |
| 優先扶養義務者の有無 | | |

> CSVの実サンプル（個人情報はダミー化）を1本いただければ、
> 上記を実際の列名・コード値に合わせて確定する。

### 5.3 バリデーション

- 必須項目の欠損 → 当該行をエラー一覧に出力し、印刷対象から除外
- 生年月日が日付として解釈できない → 同上
- CSVに存在するが抽出条件に合致しない者 → 「対象外」として件数を表示（エラーではない）

## 6. 出力・印刷仕様

### 6.1 方式

**ローカルWebアプリ（HTML → ブラウザ印刷）**

- ローカルでサーバを起動し、ブラウザで操作する
- 様式は HTML + CSS（`@page` / `size: A4` / `mm` 単位）で再現する
- 印刷はブラウザの印刷機能（Ctrl+P）を使用。「PDFとして保存」も可能
- 外部ネットワーク送信は行わない（個人情報を扱うため、完全にローカル完結）

### 6.2 印刷要件

- 対象者全員分を**1つのHTMLに連続出力**し、一括印刷できること
- 1件＝1ページとし、`page-break-after` でページを分割する
- 所属順・職員番号順に並べ、所属ごとの仕分けができること
- ブラウザのヘッダ・フッタ（URL、ページ番号）が出ない前提でレイアウトする旨を操作手順に明記
- 印刷プレビューと実印刷でズレが出ないよう、絶対単位（mm/pt）でレイアウトする

### 6.3 画面構成（案）

1. **取込画面** — CSVを選択して取り込み、件数とエラー一覧を表示
2. **条件設定画面** — 基準日・生年月日上限・対象年度を入力
3. **対象者一覧画面** — 抽出結果を確認、所属や個人単位で印刷対象を絞り込み
4. **印刷プレビュー画面** — 調査書を人数分レンダリング、そのまま印刷

## 7. 添付書類チェックリストの判定ロジック

通知【別紙】２⑶「添付書類 … 被扶養者資格確認調査と同じ。ただし、被扶養者資格確認調査と
重複している添付書類については添付の必要無し。」に基づき、別紙１⑸のルールを準用する。

### 7.1 全員

| 条件 | 添付書類 |
|---|---|
| 原則全員（無職無収入でも必要） | 所得証明書 |
| ただし**全日制の学校等の学生**は除く | — |

※「全日制の学校等」＝学校教育法に規定する学校、これに相当する海外の学校、
高校・大学等への入学を目的とした予備校。**定時制・通信制課程・夜間課程の学生等は要提出。**

### 7.2 収入がある場合

| 収入の内容 | 添付書類 |
|---|---|
| a 給与・報酬等 | 就労証明書（令和７年７月〜令和８年６月に1日でも就労していれば必要。様式を印刷し事業所から証明を受ける。**事業所の証明印の押印必須**） |
| b 年金 | 最新の年金改定通知書 又は 年金振込通知書の写 |
| c 事業収入（農業・自営業等） | 令和７年分の確定申告書及び収支内訳書の写 |
| d その他収入 | 当該収入を確認できる書類 |

### 7.3 18歳以上の全日制の学生（同居・別居とも）

- 在学証明書（令和８年４月１日以降交付のもの、**写不可**）

### 7.4 別居している場合

| 区分 | 添付書類 |
|---|---|
| a 全員（学生・施設入所者を除く。**定時制等の学生は要提出**） | 別居先世帯全員分の住民票／令和７年７月〜令和８年６月の各月の送金実績証明書（振込人・受取人の両方の氏名が記載されたもの。通帳の写等） |
| b 身体障害者授産施設、知的障害者更生施設、介護老人保健施設 入所者等 | 施設入所証明書の写 |
| c 養護老人ホーム、特別養護老人ホーム、児童福祉施設等 入所者 | 施設入所証明書の写／入所費用が確認できる書類／組合員が援助していることを客観的に証明できる書類（通帳の写等） |

### 7.5 組合員以外に優先扶養義務者がいる場合

（例: 母であれば父、孫であれば子 等）

- 優先扶養義務者の所得証明書
- 優先扶養義務者等の収入に関する証明書（収入がある場合）
- 世帯全員の住民票
  - ただし父母がともに被扶養者となっている場合、住民票は添付不要
  - 優先扶養義務者が後期高齢者医療制度の被保険者の場合、当該保険証の添付をもって住民票に代えられる

### 7.6 留意事項

- 事業所の倒産等により就労証明書が提出できない場合は申立書が必要（担当へ連絡）

### 7.7 実装上の扱い

- 上記を判定ルールとして実装し、CSVの区分値から**個人ごとの添付書類リストを自動生成**して調査書に印字する
- ただし条件の一部（施設入所区分、優先扶養義務者の有無等）はCSVに存在しない可能性が高い。
  その場合は**チェックボックス付きの一覧を全件印字**し、職員が該当欄にチェックする方式とする
- 年・期間（令和７年７月〜令和８年６月 等）は年度パラメータから自動計算する

## 10. 参考: 添付書類の例（通知 別紙３より）

**例１** 配偶者（専業主婦）、大学生の子（別居）、母（年金受給者・同居）を扶養親族としている場合

- 配偶者（専業主婦） … 所得証明書
- 大学生の子（別居） … 在学証明書
- 母（年金受給者・同居） … 所得証明書／年金改定通知書の写
- その他（父が優先扶養義務者となるため） … 父の所得証明書／父の収入に関する証明書／世帯全員分の住民票

**例２** 父母（年金受給者・別居）を扶養親族としている場合

- 父・母それぞれ … 所得証明書／年金改定通知書／別居先の世帯全員分の住民票
- その他 … 送金実績の分かる書類（通帳の写等）

**例３** 配偶者（パート）及び中学生の子を扶養親族としている場合

- 配偶者（パート） … 所得証明書／就労証明書
- 中学生の子 … なし（**本調査の対象外**）
